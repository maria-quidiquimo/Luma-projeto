# 🛍️ Luma — Lista de Compras ✨

> Um aplicativo fofo, intuitivo e organizado para você planejar suas compras com leveza e estilo! 🎀

---

## 🌸 Sobre o Luma

O **Luma** nasceu para transformar a rotina de compras em um momento charmoso e ultra funcional. Chega de papéis rasgados ou blocos de notas bagunçados — com o Luma você lista o que precisa, ajusta a quantidade exata e marca os itens conforme coloca no carrinho.

### 💕 Funcionalidades

* **📝 Adicionar Itens com Quantidade:** Defina a quantidade certa para não faltar nem sobrar nada.
* **✅ Checkbox "Comprado":** Marque seus itens no mercado com um toque simples e satisfatório.
* **🎨 Interface Girly & Clean:** Visual em tons pastéis pensado para ser lindo e agradável de usar.
* **🗑️ Gestão Prática:** Remova itens individualmente ou limpe a lista inteira ao terminar a compra.
* **💾 Salvamento Automático com AsyncStorage:** Seus itens ficam salvos no dispositivo para você não perder nada ao fechar o app.

## 🚀 Como Executar o Projeto

**Pré-requisitos:** ter o **Node.js**, **Git** e o ambiente de desenvolvimento React Native (ou Expo) configurados.

1. **Clone este repositório:**
   ```bash
   git clone [https://github.com/seu-usuario/luma.git](https://github.com/seu-usuario/luma.git)
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd luma
   ```

3. **Instale as dependências:**
   ```bash
   npm install
   # ou
   yarn install
   ```

4. **Execute a aplicação:**
   ```bash
   npm start
   ```
